# TextTiles support site

Public support and privacy pages for the TextTiles App Store listings. GitHub
Pages publishes this repository's `main` branch. After changing policy or
support copy, verify the live HTTPS pages and mirror the same source under
`support-site/` in the main `rajx240/TextTiles` repository so release review
does not drift from the public site.

- Support: <https://rajx240.github.io/texttiles-support/support.html>
- Privacy: <https://rajx240.github.io/texttiles-support/privacy.html>
